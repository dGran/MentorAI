Linux: navegación y manipulación de ficheros

ls, cd, cp, mv, rm, ln y compañía. El vocabulario básico del terminal con sus flags más útiles, los atajos que ahorran tiempo y los errores que hay que evitar.

La mayoría de comandos de navegación son simples; la riqueza está en sus flags y en combinarlos bien.

Rutas y orientación#

Toda ruta en Linux es absoluta (empieza en /) o relativa (a partir del directorio actual). Algunos atajos esenciales:

bash · rutas especiales
.          # directorio actual
..         # directorio padre
~          # home del usuario actual (/home/david)
~usuario   # home de otro usuario
-          # el directorio anterior (cd - para volver)

# Ejemplos:
cd ../config      # sube un nivel y entra en config/
cp archivo.txt ~  # copia al home
cd -              # vuelve donde estabas

Listar: ls#

bash · ls y sus flags
ls              # listado básico
ls -l           # formato largo: permisos, propietario, tamaño, fecha
ls -la          # -a incluye ficheros ocultos (empiezan por .)
ls -lh          # -h tamaños en KB/MB/GB (human readable)
ls -lt          # ordenado por fecha de modificación (más nuevo arriba)
ls -ltr         # -r reverse: más antiguo arriba (útil para logs)
ls -lS          # ordenado por tamaño (mayor primero)
ls -R           # recursivo (todos los subdirectorios)
ls -1           # un fichero por línea (útil para pipear)
ls /etc/*.conf  # glob: solo ficheros .conf en /etc

# Combinaciones útiles:
ls -lah /var/log/nginx/   # logs de nginx con tamaños legibles

La salida de ls -l tiene este formato:

bash · anatomía de ls -l
-rw-r--r-- 1 david www-data 4096 Jul  5 10:23 index.php
│          │ │     │        │    │             └── nombre
│          │ │     │        │    └── fecha de modificación
│          │ │     │        └── tamaño en bytes
│          │ │     └── grupo propietario
│          │ └── usuario propietario
│          └── número de hard links
└── permisos (tipo + owner + group + others)

Moverse: cd y pwd#

bash
pwd                     # muestra el directorio actual (Print Working Dir)
cd /var/log             # ruta absoluta
cd nginx                # ruta relativa (entra en nginx/ desde el actual)
cd ..                   # sube un nivel
cd ../..                # sube dos niveles
cd ~                    # va al home
cd                      # sin argumentos = igual que cd ~
cd -                    # vuelve al directorio anterior

Tab completion y atajos de teclado

Tab autocompleta rutas y comandos. Ctrl+R busca en el historial. Ctrl+L limpia la pantalla. Ctrl+A/E van al inicio/fin de la línea. !! repite el último comando; !nginx el último que empezó por "nginx".

Crear y organizar#

bash · mkdir y touch
mkdir logs                  # crea directorio
mkdir -p app/src/Controller # -p crea toda la ruta de una vez (sin error si existe)
mkdir -p release/{v1,v2}    # brace expansion: crea release/v1 y release/v2

touch fichero.txt           # crea fichero vacío o actualiza su timestamp
touch fichero{1,2,3}.log    # crea fichero1.log, fichero2.log, fichero3.log

Copiar y mover#

bash · cp y mv
# cp: copiar
cp origen.txt destino.txt       # copia fichero
cp -r directorio/ copia/        # -r recursivo (directorios)
cp -a directorio/ copia/        # -a preserva permisos, timestamps y symlinks
cp -i origen destino            # -i pregunta antes de sobreescribir
cp *.log /tmp/backup/           # glob: copia todos los .log

# mv: mover o renombrar
mv antiguo.txt nuevo.txt        # renombra
mv fichero.txt /tmp/            # mueve a otro directorio
mv -i origen destino            # pregunta antes de sobreescribir
mv *.log /var/log/backup/       # mueve todos los .log

mv sobreescribe sin aviso por defecto

mv a.txt b.txt destruye b.txt si existía, sin preguntar. Usa mv -i si no estás seguro. Lo mismo aplica a cp.

Borrar: rm#

bash · rm
rm fichero.txt              # borra fichero
rm -r directorio/           # borra directorio y su contenido
rm -f fichero.txt           # -f fuerza (sin error si no existe, sin preguntar)
rm -rf directorio/          # combinación más peligrosa del terminal
rm -i *.log                 # pregunta por cada fichero antes de borrar
rmdir directorio/           # borra solo directorios VACÍOS

rm -rf no tiene papelera

Linux no tiene papelera de reciclaje para el terminal. rm -rf es irreversible. Antes de ejecutarlo, prueba el comando con ls para ver exactamente qué afecta: ls -la lo-que-vas-a-borrar. Nunca copies rm -rf /algo sin leerlo.

Enlaces: ln#

Linux tiene dos tipos de enlace. Entender la diferencia importa más de lo que parece.

Hard link

bash
ln original.txt alias.txt
# Mismo inodo, dos nombres.
# Borrar uno no afecta al otro.
# Solo funciona en el mismo filesystem.
# No funciona con directorios.

Symlink (enlace simbólico)

bash
ln -s /ruta/original alias
# Inodo distinto; apunta a la ruta.
# Si borras el original = enlace roto.
# Funciona entre filesystems.
# Funciona con directorios.
bash · ejemplos reales de symlinks
# PHP usa symlinks para gestionar versiones activas:
ls -la /usr/bin/php
# lrwxrwxrwx ... /usr/bin/php -> php8.2

# Nginx: sites-available / sites-enabled
ln -s /etc/nginx/sites-available/miapp.conf \
      /etc/nginx/sites-enabled/miapp.conf

# Ver a dónde apunta un symlink:
readlink -f /usr/bin/php
ls -la /etc/nginx/sites-enabled/

Inspeccionar: stat y file#

bash
stat fichero.txt    # todo: inodo, permisos, propietario, tamaños, timestamps
file fichero        # tipo real del fichero (por contenido, no por extensión)
file imagen.jpg     # JPEG image data...
file script.sh      # Bourne-Again shell script
file binario        # ELF 64-bit LSB executable...

tree /etc/nginx     # árbol visual (requiere instalar: apt install tree)
tree -L 2 .         # árbol del directorio actual con profundidad máx 2

Resumen#

Lo que te llevas

  • ls -lah es el listado completo del día a día: largo, ocultos y tamaños legibles. ls -lt para ver lo más reciente primero.
  • cd - vuelve al directorio anterior. Tab autocompleta. Ctrl+R busca en el historial.
  • mkdir -p crea toda la ruta de una vez. cp -a preserva permisos y symlinks al copiar.
  • mv y cp sobreescriben sin aviso. Usa -i si no estás seguro del destino.
  • rm -rf es irreversible. Antes de ejecutarlo, verifica con ls qué va a borrar.
  • Los symlinks (ln -s) son la herramienta para gestionar versiones y activar configuraciones (nginx sites-enabled, versiones de PHP).
