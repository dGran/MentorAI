Slices y maps: las colecciones de Go

Los arrays de PHP son un híbrido de lista y diccionario. Go los separa en dos tipos: slice (lista tipada y redimensionable) y map (clave-valor tipado). Son las colecciones que usarás el 95% del tiempo.

Array vs slice

Go tiene dos tipos de colección secuencial: array y slice. La diferencia clave: el array tiene tamaño fijo en el tipo; el slice es dinámico.

// Array: tamaño fijo, parte del tipo
var numeros [3]int             // [0 0 0] — tamaño 3, no cambia
letras := [3]string{"a","b","c"}

// Slice: tamaño dinámico
precios := []float64{9.99, 14.99, 24.99}   // [] sin número = slice

En la práctica, usarás slices casi siempre. Los arrays aparecen en casos muy específicos: criptografía, implementaciones de bajo nivel, situaciones donde el tamaño forma parte del contrato de tipo.

Crear y usar slices

Hay tres formas habituales de crear un slice:

// 1. Literal
nombres := []string{"Ana", "Luis", "Eva"}

// 2. make: crea con longitud y opcionalmente capacidad
precios := make([]float64, 3)        // len=3, cap=3, valores en 0.0
buffer := make([]byte, 0, 64)        // len=0, cap=64 (reserva sin elementos)

// 3. nil slice: sin inicializar (len=0, cap=0, nil)
var tags []string   // nil pero válido para append

Operaciones básicas:

frutas := []string{"manzana", "pera", "naranja"}

fmt.Println(len(frutas))      // 3: número de elementos
fmt.Println(frutas[0])        // "manzana": acceso por índice
fmt.Println(frutas[1:3])      // ["pera" "naranja"]: subslice

// Añadir elementos
frutas = append(frutas, "kiwi")         // añade uno
frutas = append(frutas, "uva", "mango") // añade varios

// Eliminar por índice (sin built-in, se construye con slicing)
i := 1   // eliminar "pera"
frutas = append(frutas[:i], frutas[i+1:]...)
Nota el frutas = append(frutas, ...): append puede devolver un slice diferente al original si necesita reasignar. Siempre asigna el resultado de vuelta.

El backing array y el gotcha de append

Un slice no es un array: es una vista sobre un array subyacente (backing array). Tiene tres campos internos: un puntero al array, la longitud (len) y la capacidad (cap).

Slice
ptr → arr[0]
len=3
cap=6
→
Backing array
[1][2][3][ ][ ][ ]

Cuando el slice tiene capacidad libre, append escribe en el backing array existente. Cuando se queda sin capacidad, Go crea un nuevo backing array (aprox. el doble de grande) y copia todos los elementos. Este comportamiento tiene un gotcha importante:

original := []int{1, 2, 3}
copia := original   // los dos apuntan al MISMO backing array

copia[0] = 99
fmt.Println(original[0])   // 99: ¡original cambió!

Si necesitas una copia independiente, usa copy:

original := []int{1, 2, 3}
independiente := make([]int, len(original))
copy(independiente, original)

independiente[0] = 99
fmt.Println(original[0])   // 1: ahora sí son independientes

El gotcha de append: si dos slices comparten backing array y uno hace append dentro de la capacidad existente, modifica la memoria del otro:

base := make([]int, 3, 6)   // len=3, cap=6
base[0], base[1], base[2] = 1, 2, 3

sub := base[:2]             // [1 2]: comparte backing array con cap=4 libre
sub = append(sub, 99)       // escribe en la posición 3 del backing array compartido

fmt.Println(base)   // [1 2 99]: ¡base[2] cambió!
Cuando un slice tiene cap > len y haces append, puede modificar la memoria de slices que comparten el mismo backing array. La solución: usar s[low:high:max] para limitar la capacidad, o simplemente ser consciente de cuándo compartes backing array.

Iterar con range

El for range es la forma idiomática de iterar sobre slices y maps:

frutas := []string{"manzana", "pera", "naranja"}

// índice y valor
for i, fruta := range frutas {
    fmt.Printf("%d: %s\n", i, fruta)
}

// solo el valor (descartar índice con _)
for _, fruta := range frutas {
    fmt.Println(fruta)
}

// solo el índice
for i := range frutas {
    fmt.Println(i)
}
range sobre un slice devuelve una copia del valor. Si modificas fruta dentro del bucle, no modificas el slice original. Para modificar, usa el índice: frutas[i] = "kiwi".

Maps

Un map es un diccionario clave-valor. Ambos tipos están fijados en la declaración:

// make (recomendado: controlas el tipo explícitamente)
stock := make(map[string]int)
stock["manzana"] = 50
stock["pera"] = 30

// literal (cuando los valores son conocidos de antemano)
precios := map[string]float64{
    "manzana": 1.20,
    "pera":    0.90,
    "naranja": 0.75,
}

fmt.Println(precios["manzana"])   // 1.20
fmt.Println(precios["uva"])       // 0.0: zero value para claves inexistentes

Comprobar si una clave existe con el idioma de los dos valores:

precio, existe := precios["uva"]

if !existe {
    fmt.Println("producto no encontrado")
    return
}

fmt.Printf("precio: %.2f\n", precio)

Otras operaciones habituales:

delete(precios, "pera")   // eliminar una clave

fmt.Println(len(precios)) // número de entradas

// iterar (orden no garantizado)
for producto, precio := range precios {
    fmt.Printf("%s: %.2f€\n", producto, precio)
}
Los maps no son seguros para escritura concurrente. Si múltiples goroutines leen y escriben en el mismo map, necesitas un mutex (sync.RWMutex) o usar sync.Map. Leer en paralelo sin escrituras es seguro.

Maps vs arrays PHP

PHP: arrays asociativos

$precios = [
    "manzana" => 1.20,
    "pera"    => 0.90,
];

// Clave puede existir o no — no hay error
echo $precios["uva"] ?? "no existe";

// Tipado dinámico: cualquier valor
$mezcla = ["nombre" => "Ana", "edad" => 30];

Go: maps tipados

precios := map[string]float64{
    "manzana": 1.20,
    "pera":    0.90,
}

// Acceso seguro con idioma de dos valores
precio, existe := precios["uva"]
if !existe {
    fmt.Println("no existe")
}

// Las claves y valores deben ser del mismo tipo declarado
// map[string]any para mezclar tipos (equivale al array PHP)

Cuando necesitas flexibilidad de tipos en Go, puedes usar map[string]any (any es el alias de interface{}), aunque suele indicar que hay un diseño mejor con structs tipados.

Resumen

  • Array tiene tamaño fijo ([3]int); slice tiene tamaño dinámico ([]int). Usa slices salvo caso muy específico.
  • len = elementos actuales; cap = espacio en el backing array. append puede reasignar si se queda sin cap; siempre asigna el resultado de vuelta.
  • Dos slices que comparten backing array se afectan mutuamente si se escribe dentro de la capacidad compartida. Usa copy para una copia independiente.
  • for i, v := range slice para iterar. El valor v es una copia; modifica con el índice si necesitas alterar el slice.
  • map[K]V = clave-valor tipado. El acceso a clave inexistente devuelve el zero value; usa el idioma v, ok := m[k] para saber si existe.
  • Los maps no son seguros para escritura concurrente; usa un mutex si múltiples goroutines escriben.
