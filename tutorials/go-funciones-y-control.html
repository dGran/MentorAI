Funciones y control de flujo en Go

Go tiene retornos múltiples, un único bucle for que hace todo lo que PHP hace con while/foreach/for, un switch que no cae al siguiente caso por defecto, y defer para garantizar limpieza de recursos.

Funciones

La sintaxis de una función en Go es diferente de PHP: el tipo va después del nombre, no antes:

PHP

function sumar(int $a, int $b): int {
    return $a + $b;
}

Go

func sumar(a int, b int) int {
    return a + b
}

// Tipos iguales consecutivos: se puede simplificar
func sumar(a, b int) int {
    return a + b
}

Las funciones son valores de primera clase en Go: se pueden asignar a variables, pasar como argumentos y devolver desde otras funciones:

// Función como variable
operacion := func(a, b int) int {
    return a + b
}
resultado := operacion(3, 4)   // 7

// Función que devuelve una función (closure)
func multiplicador(factor int) func(int) int {
    return func(x int) int {
        return x * factor
    }
}

doble := multiplicador(2)
triple := multiplicador(3)
fmt.Println(doble(5))    // 10
fmt.Println(triple(5))   // 15

Retornos múltiples

Go puede devolver varios valores de una función. Este mecanismo es la base del manejo de errores en Go (ver lección go-errores):

func dividir(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("no se puede dividir por cero")
    }

    return a / b, nil
}

// El llamador maneja ambos valores
resultado, err := dividir(10, 3)

if err != nil {
    log.Fatal(err)
}

fmt.Printf("%.2f\n", resultado)   // 3.33

El guión bajo (_) descarta un valor de retorno que no necesitas:

resultado, _ := dividir(10, 2)   // ignoramos el error (solo si estamos seguros)
Ignorar el error con _ es legítimo cuando sabes con certeza que no puede fallar. Hacerlo por comodidad es una fuente de bugs silenciosos. Cuando no estés seguro, maneja el error.

if y el if con init

El if de Go no necesita paréntesis alrededor de la condición (si los pones, gofmt los elimina). Las llaves son obligatorias:

if edad >= 18 {
    fmt.Println("adulto")
} else if edad >= 13 {
    fmt.Println("adolescente")
} else {
    fmt.Println("menor")
}

El if con inicializador es idiomático en Go: permite declarar una variable en el propio if, cuyo ámbito queda limitado al bloque:

// En lugar de:
resultado, err := dividir(10, 3)
if err != nil {
    return err
}

// Idioma Go: declarar y comprobar en la misma línea
if resultado, err := dividir(10, 3); err != nil {
    return err
} else {
    fmt.Println(resultado)   // resultado solo existe aquí
}

El único bucle: for

Go tiene un solo tipo de bucle: for. Pero es tan flexible que sustituye a while, foreach y for de PHP:

// For clásico (equivalente al for de PHP)
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// For como while (condición sola)
n := 1
for n < 100 {
    n *= 2
}

// Bucle infinito
for {
    // solo sale con break o return
    if condicion {
        break
    }
}

// Range sobre un slice (equivalente al foreach de PHP)
frutas := []string{"manzana", "pera", "uva"}

for i, fruta := range frutas {
    fmt.Printf("[%d] %s\n", i, fruta)
}

// Range descartando el índice
for _, fruta := range frutas {
    fmt.Println(fruta)
}

// Range sobre un map
precios := map[string]float64{"manzana": 1.5, "pera": 2.0}

for clave, valor := range precios {
    fmt.Printf("%s: %.2f€\n", clave, valor)
}

// Range sobre un string itera sobre runes (caracteres Unicode)
for i, caracter := range "hola" {
    fmt.Printf("[%d] %c\n", i, caracter)
}

switch sin fallthrough

El switch de Go no necesita break al final de cada caso: por defecto no cae al siguiente. Es lo contrario de PHP/JavaScript, donde hay que acordarse de poner break:

PHP: fallthrough por defecto

switch ($nivel) {
    case "principiante":
        echo "verde";
        break;        // si te olvidas, cae al siguiente
    case "avanzado":
        echo "rojo";
        break;
}

Go: no cae por defecto

switch nivel {
case "principiante":
    fmt.Println("verde")    // no necesita break
case "avanzado":
    fmt.Println("rojo")
}

Si quieres el fallthrough explícito (raro), usa la palabra clave fallthrough. El switch puede evaluar condiciones en cada caso, sin variable:

// Switch con condición en cada case
switch {
case edad < 13:
    fmt.Println("niño")
case edad < 18:
    fmt.Println("adolescente")
default:
    fmt.Println("adulto")
}

// Switch con type assertion (útil con interfaces)
switch v := interfaz.(type) {
case int:
    fmt.Printf("entero: %d\n", v)
case string:
    fmt.Printf("cadena: %s\n", v)
default:
    fmt.Printf("tipo desconocido: %T\n", v)
}

defer: garantizar limpieza

defer pospone la ejecución de una función hasta que la función que la contiene retorna. Se ejecuta siempre: aunque haya un error de por medio. Es el mecanismo de Go para garantizar que los recursos se liberen.

func leerFichero(ruta string) error {
    f, err := os.Open(ruta)

    if err != nil {
        return err
    }

    defer f.Close()   // se ejecuta cuando leerFichero retorne, pase lo que pase

    // ... leer contenido del fichero
    return nil
}

Múltiples defer se ejecutan en orden LIFO (último en declararse, primero en ejecutarse):

func ejemplo() {
    defer fmt.Println("tercero")
    defer fmt.Println("segundo")
    defer fmt.Println("primero")
    fmt.Println("cuerpo")
}
// Salida:
// cuerpo
// primero
// segundo
// tercero
El patrón más común de defer: abrir un recurso → diferir su cierre → trabajar con él. Así nunca se olvida cerrar el fichero, liberar el mutex o cerrar la conexión a la BD, aunque la función salga por un return inesperado.

Resumen

  • La sintaxis de función en Go pone los tipos después del nombre: func nombre(param tipo) tipo.
  • Los retornos múltiples son idiomáticos: la segunda variable de retorno suele ser error.
  • _ descarta valores de retorno no necesarios.
  • Un solo bucle for cubre los casos de for, while y foreach de PHP. range itera sobre slices, maps y strings.
  • El switch no cae al siguiente caso por defecto. No se necesita break.
  • defer garantiza que una función se ejecute al salir del scope, independientemente de cómo: el mecanismo estándar para liberar recursos.
