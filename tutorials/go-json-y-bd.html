JSON y base de datos

Go maneja JSON con struct tags: marcas que le indican al encoder/decoder cómo mapear campos. Para bases de datos, database/sql es la interfaz estándar: queries parametrizadas seguras, escáner de resultados y transacciones, sin ORM.

Serializar structs a JSON

El paquete encoding/json serializa cualquier struct cuyos campos sean exportados (mayúscula). Marshal devuelve bytes; NewEncoder escribe directamente a un io.Writer (como un http.ResponseWriter):

type Producto struct {
    ID     int     `json:"id"`
    Nombre string  `json:"nombre"`
    Precio float64 `json:"precio"`
}

p := Producto{ID: 1, Nombre: "Mesa", Precio: 299.99}

// Serializar a bytes
datos, err := json.Marshal(p)
// {"id":1,"nombre":"Mesa","precio":299.99}

// Serializar directamente al ResponseWriter (más eficiente)
w.Header().Set("Content-Type", "application/json")
json.NewEncoder(w).Encode(p)

Deserializar JSON a structs

body := `{"id":1,"nombre":"Mesa","precio":299.99}`
var producto Producto

// Desde string/bytes
err := json.Unmarshal([]byte(body), &producto)

// Desde el cuerpo de una petición HTTP (más eficiente)
err = json.NewDecoder(r.Body).Decode(&producto)

if err != nil {
    http.Error(w, "JSON inválido", http.StatusBadRequest)
    return
}

fmt.Println(producto.Nombre)   // Mesa
Limita el tamaño del body antes de decodificar para evitar ataques de agotamiento de memoria: r.Body = http.MaxBytesReader(w, r.Body, 1_000_000) (1 MB).

Struct tags

Las struct tags son metadatos entre comillas invertidas que controlan cómo encoding/json trata cada campo:

type Usuario struct {
    ID        int       `json:"id"`
    Nombre    string    `json:"nombre"`
    Email     string    `json:"email"`
    Password  string    `json:"-"`              // nunca serializado
    CreatedAt time.Time `json:"created_at"`
    UpdatedAt time.Time `json:"updated_at,omitempty"` // omitir si zero value
    Interno   string    `json:"-,"`             // nombre literal "-" en JSON
}

Las opciones más habituales:

  • json:"nombre": nombre del campo en JSON (snake_case por convención).
  • json:"-": excluir completamente del JSON (contraseñas, datos internos).
  • json:"campo,omitempty": omitir si el campo es el zero value (0, "", nil, false).

database/sql: conectar y consultar

database/sql es la interfaz estándar de Go para bases de datos. Necesitas un driver externo (solo el driver, no un ORM completo):

go get github.com/lib/pq          # driver PostgreSQL clásico
# o
go get github.com/jackc/pgx/v5    # driver moderno, recomendado

import (
    "database/sql"
    _ "github.com/lib/pq"   // registra el driver con un init()
)

func conectar(dsn string) (*sql.DB, error) {
    db, err := sql.Open("postgres", dsn)

    if err != nil {
        return nil, fmt.Errorf("abrir conexión: %w", err)
    }

    db.SetMaxOpenConns(25)
    db.SetMaxIdleConns(10)
    db.SetConnMaxLifetime(5 * time.Minute)

    if err = db.PingContext(context.Background()); err != nil {
        return nil, fmt.Errorf("ping a la base de datos: %w", err)
    }

    return db, nil
}

sql.Open no conecta: solo valida el DSN. La conexión real se hace al primer uso o con Ping. *sql.DB es un pool de conexiones: es seguro para uso concurrente y debe crearse una sola vez.

Escanear resultados

Las queries parametrizadas con $1, $2... son siempre seguras contra SQL injection:

// Una fila: QueryRowContext
func buscarProducto(ctx context.Context, db *sql.DB, id int) (*Producto, error) {
    var p Producto

    err := db.QueryRowContext(ctx,
        "SELECT id, nombre, precio FROM productos WHERE id = $1", id).
        Scan(&p.ID, &p.Nombre, &p.Precio)

    if errors.Is(err, sql.ErrNoRows) {
        return nil, nil   // no existe, no es error
    }

    if err != nil {
        return nil, fmt.Errorf("buscar producto %d: %w", id, err)
    }

    return &p, nil
}

// Múltiples filas: QueryContext
func listarProductos(ctx context.Context, db *sql.DB) ([]Producto, error) {
    rows, err := db.QueryContext(ctx, "SELECT id, nombre, precio FROM productos ORDER BY id")

    if err != nil {
        return nil, fmt.Errorf("listar productos: %w", err)
    }

    defer rows.Close()   // siempre cerrar rows

    var productos []Producto

    for rows.Next() {
        var p Producto

        if err := rows.Scan(&p.ID, &p.Nombre, &p.Precio); err != nil {
            return nil, fmt.Errorf("scan producto: %w", err)
        }

        productos = append(productos, p)
    }

    if err := rows.Err(); err != nil {
        return nil, fmt.Errorf("iterar productos: %w", err)
    }

    return productos, nil
}

Transacciones

func transferir(ctx context.Context, db *sql.DB, origen, destino int, cantidad float64) error {
    tx, err := db.BeginTx(ctx, nil)

    if err != nil {
        return fmt.Errorf("iniciar transacción: %w", err)
    }

    defer tx.Rollback()   // no-op si ya se hizo Commit

    _, err = tx.ExecContext(ctx,
        "UPDATE cuentas SET saldo = saldo - $1 WHERE id = $2", cantidad, origen)

    if err != nil {
        return fmt.Errorf("debitar cuenta %d: %w", origen, err)
    }

    _, err = tx.ExecContext(ctx,
        "UPDATE cuentas SET saldo = saldo + $1 WHERE id = $2", cantidad, destino)

    if err != nil {
        return fmt.Errorf("acreditar cuenta %d: %w", destino, err)
    }

    return tx.Commit()
}

El patrón defer tx.Rollback() justo después de BeginTx garantiza que la transacción se revierte si algo falla antes del Commit. Si Commit tuvo éxito, el Rollback del defer es un no-op.

Resumen

  • json.Marshal / json.Unmarshal para bytes; json.NewEncoder(w).Encode / json.NewDecoder(r.Body).Decode para streams.
  • Las struct tags (`json:"campo,omitempty"`) controlan nombre, omisión y exclusión de campos en JSON.
  • database/sql es la interfaz estándar. Configura el pool de conexiones (MaxOpenConns, MaxIdleConns). El pool es seguro para uso concurrente.
  • Usa siempre queries parametrizadas ($1, $2...). Cierra siempre rows con defer rows.Close(). Comprueba siempre rows.Err() al final.
  • Transacciones: defer tx.Rollback() justo después de BeginTx. El rollback del defer es no-op si Commit ya tuvo éxito.
