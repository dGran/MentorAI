Linux: búsquedas con find, grep y xargs

Dos herramientas que, bien manejadas, te permiten localizar cualquier cosa en el sistema en segundos: find busca ficheros por atributos; grep busca texto dentro de ficheros. xargs las une.

La búsqueda es una de las habilidades que más diferencia a quien usa el terminal como herramienta de quien simplemente lo tolera.

find básico#

find recorre el árbol de directorios y filtra ficheros por sus atributos. La sintaxis es: find [punto de partida] [condiciones] [acciones].

bash · por nombre y tipo
find . -name "*.php"            # todos los .php desde aquí (recursivo)
find /var/log -name "*.log"     # .log en /var/log
find . -name "config.php"       # fichero exacto
find . -iname "*.PHP"           # -iname: insensible a mayúsculas
find . -name "*.php" -not -name "*test*"  # .php que no contengan "test"

find . -type f                  # solo ficheros regulares
find . -type d                  # solo directorios
find . -type l                  # solo symlinks
find /etc -type f -name "*.conf"   # ficheros .conf en /etc

find: filtros avanzados#

bash · por tamaño
find / -size +100M -type f      # ficheros de más de 100 MB
find . -size -1k -type f        # ficheros de menos de 1 KB
find . -size +1M -size -10M     # entre 1 MB y 10 MB
# Unidades: c (bytes), k (KB), M (MB), G (GB)
bash · por fecha de modificación
find . -mtime -1                # modificados en las últimas 24h
find . -mtime +7                # modificados hace más de 7 días
find . -mtime +30 -name "*.log" # logs de más de 30 días (candidatos a borrar)
find . -newer referencia.txt    # más nuevos que referencia.txt
find . -mmin -60                # modificados en los últimos 60 minutos
bash · por permisos y propietario
find . -perm 777                # exactamente 777
find . -perm -o+w               # others tiene write (permiso peligroso)
find . -perm /u+s               # ficheros con setuid activo
find /var/www -user www-data    # propietario es www-data
find /var/www -group www-data   # grupo es www-data
find . -user root -type f       # ficheros de root
bash · combinar condiciones
find . -name "*.log" -a -size +10M          # AND (implícito)
find . -name "*.log" -o -name "*.tmp"       # OR
find . -not -name "*.php"                   # NOT (alias: !)
find . \( -name "*.jpg" -o -name "*.png" \) -size +1M   # paréntesis agrupan

# Profundidad de búsqueda:
find . -maxdepth 2 -name "*.php"    # solo hasta 2 niveles de profundidad
find . -mindepth 2 -name "*.php"    # desde el nivel 2 en adelante

find: acciones#

bash · -exec y -delete
# -exec: ejecuta un comando por cada resultado
# {} = el fichero encontrado; \; = fin del comando
find . -name "*.php" -exec chmod 644 {} \;

# -exec con +: pasa todos los resultados de una vez (más eficiente)
find . -name "*.php" -exec chmod 644 {} +

# Casos reales:
find /tmp -mtime +7 -type f -delete         # borra logs viejos (cuidado)
find /var/www -name "*.php" -exec grep -l "eval(" {} \;   # busca eval() en PHP
find . -name "*.log" -exec gzip {} \;       # comprime todos los logs
find . -empty -type f -delete               # borra ficheros vacíos
find . -empty -type d -delete               # borra directorios vacíos

Prueba sin -delete primero

Antes de usar find ... -delete o -exec rm, ejecuta el mismo comando sin esa acción para ver exactamente qué va a afectar. Una vez borrado, no hay papelera.

grep básico#

grep busca texto dentro de ficheros. Imprime las líneas que contienen el patrón.

bash · grep esencial
grep "patrón" fichero.txt           # líneas que contienen el patrón
grep -i "error" access.log          # -i insensible a mayúsculas
grep -n "Exception" app.log         # -n muestra número de línea
grep -c "404" access.log            # -c cuenta el número de coincidencias
grep -v "200" access.log            # -v invierte: líneas que NO contienen el patrón
grep -l "TODO" *.php                # -l solo muestra el nombre de fichero (no las líneas)
grep -r "DB_PASSWORD" /var/www      # -r recursivo en directorio
grep -rn "die()" /var/www/html      # recursivo + número de línea

grep avanzado#

bash · contexto y regex
grep -A 3 "Fatal error" error.log   # -A 3: muestra 3 líneas después del match
grep -B 2 "Fatal error" error.log   # -B 2: muestra 2 líneas antes
grep -C 2 "Fatal error" error.log   # -C 2: 2 antes Y 2 después (Context)

# Expresiones regulares extendidas con -E (o usar egrep):
grep -E "error|warning|fatal" app.log   # OR entre patrones
grep -E "^2026-07" app.log              # líneas que empiezan por "2026-07"
grep -E "\b404\b" access.log            # palabra exacta 404
grep -E "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}" access.log  # IPs

# Buscar string literal (sin interpretar regex):
grep -F "function()" fichero.php    # -F fijo, no interpreta . * etc.

# Excluir ficheros o directorios:
grep -r "password" /var/www --include="*.php"    # solo en .php
grep -r "TODO" . --exclude="*.min.js"            # excluye minificados
grep -r "TODO" . --exclude-dir=vendor            # excluye directorio vendor
bash · casos reales de grep
# Buscar errores PHP en el log:
grep -E "PHP (Fatal|Warning|Error)" /var/log/php/error.log | tail -50

# Contar peticiones 500 del día de hoy:
grep "$(date +%d/%b/%Y)" /var/log/nginx/access.log | grep -c " 500 "

# Buscar qué ficheros PHP usan una función deprecada:
grep -rn "mysql_query" /var/www --include="*.php" -l

# Encontrar todas las rutas de API en el código:
grep -rE "@Route\(\"(/api/[^\"]+)" src/ -h -o | sort -u

xargs: encadenar resultados#

xargs toma líneas de la entrada estándar y las pasa como argumentos a otro comando. Es el puente entre find/grep y las herramientas que actúan sobre los resultados.

bash
# find piped a xargs (más eficiente que -exec para muchos ficheros):
find . -name "*.log" -mtime +30 | xargs rm
find . -name "*.php" | xargs grep -l "eval("   # busca eval() en todos los .php

# Cuando los nombres tienen espacios: usar -print0 + xargs -0
find . -name "* *" -print0 | xargs -0 ls -la

# -I {} para controlar dónde va el argumento:
find . -name "*.sql" | xargs -I {} gzip {}

# -P para paralelismo:
find . -name "*.jpg" | xargs -P 4 -I {} convert {} -resize 800x {}

# grep + xargs para buscar en los ficheros encontrados por find:
find . -name "*.php" | xargs grep -n "password"

# Contar líneas de todos los PHP del proyecto:
find . -name "*.php" | xargs wc -l | tail -1

locate, which, whereis#

bash
locate php.ini          # busca en una base de datos pre-indexada (muy rápido)
updatedb                # actualiza la base de datos de locate (como root)
# locate no ve cambios recientes hasta el próximo updatedb

which php               # ruta del ejecutable que usaría el shell
which php8.2            # ruta de php8.2
which -a php            # -a muestra todas las coincidencias en el PATH

whereis php             # binario + páginas de manual + código fuente
type ls                 # si es alias, función, builtin o ejecutable
type ll                 # "ll is aliased to 'ls -alF'"

Cuándo aplicarlo#

Úsalo cuando…

  • Buscar ficheros por nombre, fecha, tamaño o permisos: usa find
  • Buscar texto dentro de ficheros: usa grep (o ripgrep en proyectos de código)
  • Búsqueda rápida por nombre y la base de datos está actualizada: usa locate

No lo uses cuando…

  • No uses find para buscar contenido dentro de ficheros: es muy lento, usa grep
  • No uses locate en sistemas donde updatedb no corre regularmente: los resultados serán obsoletos

Resumen#

Lo que te llevas

  • find [ruta] -name "*.ext" -type f es la base. Añade -size, -mtime, -user y -perm para afinar.
  • find ... -exec comando {} + es más eficiente que \; para muchos ficheros. Siempre prueba sin la acción destructiva primero.
  • grep -rn "patrón" directorio busca recursivo con número de línea. -l solo muestra ficheros; -v invierte; -C 2 añade contexto.
  • grep -E activa expresiones regulares extendidas: error|warning, anclas ^/$, rangos [0-9]+.
  • xargs convierte líneas de stdin en argumentos. Con nombres con espacios: find -print0 | xargs -0.
  • which php dice qué ejecutable usa el shell. locate busca rapidísimo en un índice; updatedb actualiza ese índice.
