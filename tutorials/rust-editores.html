rust-analyzer

rust-analyzer es el servidor LSP oficial de Rust. A diferencia de una simple extensión de sintaxis, ejecuta el compilador de Rust en segundo plano y expone sus diagnósticos al editor: tipos inferidos al hacer hover, errores antes de guardar, autocompletado basado en el análisis real del código, y refactors como renombrar símbolo o extraer función.

Antes de rust-analyzer existía el plugin RLS, que era lento y limitado. rust-analyzer lo reemplazó completamente en 2021 y hoy es la herramienta de referencia para cualquier editor con soporte LSP.

Por qué importa tanto: Rust tiene un sistema de tipos avanzado con inferencia agresiva. Sin rust-analyzer, trabajar con Rust es frustrante: no sabes qué tipo tiene una variable, no ves los errores del borrow checker hasta compilar, no hay refactors automáticos. Con él, el editor se convierte en un asistente del compilador.

rust-analyzer entiende el sistema de módulos de Cargo, los workspaces y las features. Cuando abres un proyecto Cargo, lo indexa completo y mantiene el índice actualizado mientras editas.

VS Code + rust-analyzer

La extensión oficial se llama rust-analyzer (identificador rust-lang.rust-analyzer). Instálala desde el marketplace y reinicia VS Code. La extensión descarga rust-analyzer automáticamente si no lo encuentra en el PATH.

Para un flujo productivo, añade esto a tu .vscode/settings.json del proyecto:

{
  "editor.formatOnSave": true,
  "[rust]": {
    "editor.defaultFormatter": "rust-lang.rust-analyzer"
  },
  "rust-analyzer.checkOnSave": true,
  "rust-analyzer.checkOnSave.command": "clippy",
  "rust-analyzer.inlayHints.parameterHints.enable": true,
  "rust-analyzer.inlayHints.typeHints.enable": true
}

Con checkOnSave.command: "clippy" el editor ejecuta Clippy en cada guardado, no solo el compilador básico. Ves sugerencias de mejora en línea, sin salir del editor.

Los inlay hints muestran los tipos inferidos directamente en el código, en gris junto a las variables. Con un sistema de tipos como el de Rust, donde la inferencia cubre casi todo, esto es esencial para saber qué tipo tiene cada expresión sin hacer hover constante.

RustRover de JetBrains

JetBrains lanzó RustRover como IDE dedicado a Rust. Para quien viene de PhpStorm, la transición es inmediata: mismo sistema de atajos, misma paleta de comandos, mismo debugger visual integrado, mismo soporte de Git.

RustRover incluye rust-analyzer integrado y añade encima el motor de análisis de JetBrains: navegación más potente, búsquedas estructurales, y el debugger con breakpoints visuales. En VS Code, el debugger requiere configurar la extensión CodeLLDB por separado.

Para equipos PHP: si tu equipo ya usa PhpStorm, RustRover tiene sentido directo. Si usas VS Code para todo lo demás, quédate en VS Code con rust-analyzer: la experiencia es muy similar y evitas cambiar de herramienta.

RustRover tiene licencia de pago, pero ofrece prueba gratuita de 30 días y licencias gratuitas para proyectos open source y estudiantes.

Clippy: el linter que enseña Rust

Clippy es el linter oficial de Rust. Va mucho más allá de detectar errores: sugiere el idioma correcto de Rust cuando detecta patrones no idiomáticos.

cargo clippy

Por ejemplo, si escribes esto:

if x == true {
    println!("sí");
}

Clippy avisa: warning: comparison to true is better expressed as the value itself, y propone if x {. No es un error del compilador, pero sí código no idiomático en Rust.

Otros ejemplos de lo que detecta Clippy:

  • Usar .clone() cuando puedes tomar una referencia prestada en su lugar.
  • Iterar con índices (for i in 0..v.len()) cuando podrías usar for item in &v.
  • Llamar a unwrap() donde debería manejarse el error con ? o match.
  • Comparaciones redundantes o lógica que se simplifica con un método de la stdlib.

Para proyectos en producción, activar el grupo pedantic da un nivel de calidad muy alto:

cargo clippy -- -W clippy::pedantic

rustfmt: formateo automático

rustfmt es el formateador oficial. Aplica el estilo canónico de Rust sin discusión: indentación de 4 espacios, llaves en la misma línea, longitud máxima de 100 caracteres por defecto.

cargo fmt

La ventaja sobre gofmt es que rustfmt es configurable vía rustfmt.toml en la raíz del proyecto:

max_width = 120
tab_spaces = 4
edition = "2021"
imports_granularity = "Crate"
group_imports = "StdExternalCrate"

imports_granularity = "Crate" agrupa los imports del mismo crate en un único use con llaves. group_imports = "StdExternalCrate" separa automáticamente stdlib, crates externas y propias en tres bloques distintos.

En CI: añade cargo fmt --check al pipeline. Falla si algún fichero no está formateado, igual que php-cs-fixer --dry-run en PHP.

Acceso al contenedor desde el editor

En el entorno dockerizado del tutorial anterior, el código vive en un volumen montado desde el host. El editor edita los ficheros directamente y cargo-watch dentro del contenedor los compila al guardar. Para la mayoría de casos, esto es suficiente.

Cuando necesitas que rust-analyzer también corra dentro del contenedor (para resolver dependencias que tienen bibliotecas del sistema), tienes dos opciones:

VS Code Dev Containers: la extensión ms-vscode-remote.remote-containers conecta VS Code al interior del contenedor. rust-analyzer corre dentro, tiene acceso al toolchain y al Cargo.lock, y resuelve todo correctamente. Añade .devcontainer/devcontainer.json:

{
  "name": "Rust",
  "dockerComposeFile": "../compose.yml",
  "service": "app",
  "workspaceFolder": "/app",
  "extensions": ["rust-lang.rust-analyzer"]
}

RustRover Remote SSH: RustRover soporta conexión a hosts remotos vía SSH, incluyendo contenedores con SSH habilitado. Añade el servidor SSH al contenedor en el Dockerfile de desarrollo y conéctate desde JetBrains Gateway.

Para empezar: el volumen montado (.:/app) con rust-analyzer en el host es suficiente para los primeros proyectos. Dev Containers aporta valor cuando las dependencias del sistema difieren entre el host y el contenedor.

Resumen

  • rust-analyzer es imprescindible: analiza en tiempo real, muestra tipos inferidos, detecta errores del borrow checker antes de compilar y ofrece refactors.
  • VS Code con checkOnSave: "clippy" da una experiencia excelente sin coste de licencia.
  • RustRover es la opción natural para equipos de JetBrains: mismos atajos, debugger visual integrado sin configuración extra.
  • Clippy va más allá del compilador: enseña el idioma correcto de Rust con más de 700 lints organizados por categoría.
  • rustfmt elimina toda discusión de estilo; cargo fmt --check en CI garantiza consistencia.
  • Dev Containers conecta VS Code al interior del contenedor para que rust-analyzer resuelva dependencias del sistema correctamente.
